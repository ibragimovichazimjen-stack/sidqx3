# ТГМУ MedLib — Единая библиотека учебных материалов

Единый портал Таджикского государственного медицинского университета им. Абуали ибн Сины,
куда студенты и преподаватели загружают все учебные материалы: лекции, презентации,
учебники, методички, тесты, видео и атласы.

## Возможности

- 📚 **Каталог** — поиск и фильтры по типу, факультету, кафедре и языку (RU/TG/EN)
- 🎓 **6 факультетов и 25 кафедр** ТГМУ с навигацией по структуре университета
- ⬆ **Загрузка материалов** — drag & drop, до 100 МБ, модерация для новых файлов
- ⭐ **Избранное**, скачивания, рейтинг, теги, сортировка
- 👤 **Роли**: студент / преподаватель / администратор (админка с модерацией)
- 📱 Адаптивный дизайн для телефона и компьютера

## Запуск

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Данные хранятся в браузере (localStorage). Для боевого режима нужно подключить
серверный бэкенд (API + хранилище файлов) — структура данных в `js/data.js`
и `js/app.js` готова к этому: `materials`, `faculties`, `departments`, `types`.

## Структура

```
index.html      — разметка всех страниц (SPA)
css/style.css   — стили
js/data.js      — факультеты, кафедры, типы, стартовые материалы
js/app.js       — логика: каталог, фильтры, загрузка, профиль, админка
```
